## 手柄 R2 失灵二轮修复（G-010 收尾，真机验证通过）
- 首轮只在 Activity.dispatchGenericMotionEvent 接了 TriggerAxisKeys 合成器，Artemis 下无效：
  按键焦点在独立悬浮窗 mouseKeyCatcher/panelKeyCatcher，轴事件进 View 树被默认丢弃，
  根本到不了 Activity（这也是 Artemis 左摇杆一直不驱光标的隐患）。
- 二轮：两个 catcher View 各加 dispatchGenericMotionEvent override，
  与 Activity 共用 routeMotionFromCatcher（扳机合成 → 面板吞轴 → 摇杆驱动光标）。
- 真机验证：R2 连续切换 `trigger axis → synthetic key code=105` →
  `mouse_toggle → virtual mouse ON/OFF`。另注：Xbox 1708 蓝牙扳机轴-only 是
  连接模式相关的——老版本时代曾产生过 keycode 105（ KRKR 提交 be3aed2 当时真机验证过）。
- 教训：覆盖窗持焦的宿主，轴事件必须在 **View 层**接住；"很早之前可以"≠代码回归，
  可能只是手柄连接模式/键位布局变了。
