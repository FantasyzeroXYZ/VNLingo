# 游戏内提取与制卡功能方案（提取面板 / 查词典 / 翻译 / TTS / 截图 / 右缘按键组）

> 状态：**已实施**；移植实施记录见文末「实施记录」
> 目标：为多引擎游戏提供运行时「当前对话文本 + 配对语音 + 截图」实时提取能力，配套查词典、AnkiDroid 制卡、双轨翻译（OpenAI 兼容 API / ML Kit 离线）、TTS 朗读（系统 / MultiTTS）、游戏画面截图与游玩统计；交互入口为右缘固定按键组 + 提取面板。
> 关联：`PROGRESS.md`（进度）、`MEMORY.md`（环境/踩坑/决策）。本仓库文档以自身为准，上游继承文档已于 2026-10-05 移除。
> 移植来源：FantasyzeroXYZ 本地仓库 Tyranor-Next（同源项目的提取功能线，已在 ONS/Web/Artemis 宿主上真机模拟器实测）。

## 0. 术语表

**提取面板（剧情文本框）**: 游戏运行时叠加在画面上的实时提取面板：当前句栏（词元点查义）、配对语音、翻译行、历史列表、听力模式与制卡/复制/播放操作；由 `ExtractFacade` 接口解耦宿主（ONS/Web/Artemis/KRKR），手柄 RB 呼出。
_Avoid_: 悬浮字幕、控制台

**右缘按键组**: 游戏画面右缘固定竖排的 40dp 圆形图标键列：文本框开关/截图/设置/音量（百分比滑条）/点击模式/回主页（确认弹窗），顶部折叠键常驻；贴系统栏 inset 排布。
_Avoid_: 悬浮球（可拖动 chip 语义）、工具栏

**虚拟鼠标模式**: 用手柄 D-pad/左摇杆移动覆盖层光标、A 键注入点击的操控模式（`OnsVirtualMouse`），与触摸直传模式经右缘按键切换；仅 ONS 宿主提供。
_Avoid_: 触控模拟（触摸注入路径的统称）

**查词典**: 提取面板句栏词元点按后经本地词典查询释义：最长前缀递减 + `OnsDeinflector` 词形还原分层；词典来源 Yomichan zip / MDX jsonl（SAF 导入 SQLite，多词典管理、当前词典优先）。
_Avoid_: 在线翻译（翻译是另一条线）

**制卡（Anki）**: 把当前句/查词结果一键写入 AnkiDroid（vendored 官方 API）：词卡（Word/Reading/Meaning/Sentence）与句卡（Front=当前句，Back=截图+语音+整页），牌组/模型 `TyranorNext` 自动创建。
_Avoid_: 导出卡片（无中间文件）

## 1. 需求与范围

| 能力 | 说明 |
|---|---|
| 提取面板 | 当前句栏（词元点查义）、配对语音 ♪、翻译行、历史列表（回放原声）、听力模式（遮文本练听力）、面板透明度调节 |
| 宿主事件源 | ONS（`libonsyuri.so` 内置钩子 + JNI 上行）、Web（`__tn_extract.js` 注入 Tyrano/RPG Maker MV/MZ）、Artemis（内核 extract_bridge，外部源码仓）、KRKR（接收端就绪，内核钩子已在 `krkr_bridge.cpp`） |
| 查词典 | Yomichan zip / MDX jsonl 经 SAF 导入本地 SQLite（多词典管理：启停/删除/设为当前），最长前缀 + 词形还原分层查询 |
| 翻译双轨 | OpenAI 兼容 chat/completions（HttpURLConnection 无新依赖）与 ML Kit on-device 离线翻译（zh/en/ja/ko 模型按需下载），面板内翻译测试 |
| TTS 朗读 | 系统 TextToSpeech（按锁定字符集选语言）与 MultiTTS HTTP 合成双路径，自动朗读/语速调节 |
| 制卡（Anki） | AnkiDroid vendored API：词卡（Word/Reading/Meaning/Sentence）与句卡（Front=当前句、Back=截图+语音+整页） |
| 截图 | PixelCopy 游戏 SurfaceView（只含游戏画面，不含覆盖层），主页截图管理页（网格/大图/分享/删除） |
| 游玩统计 | engine `PlayTimeTracker`（60s 周期落盘）+ 应用「游玩统计」页（总/周/月三卡 + 每游戏列表） |
| 右缘按键组 | 文本框开关/截图/设置/音量（百分比滑条）/点击模式/回主页（确认弹窗），顶部折叠键（折叠后常驻顶端） |
| 点击模式 | 虚拟鼠标（D-pad/左摇杆移光标 + A 键点击，`OnsVirtualMouse`）与触摸直传切换 |

**非目标（本方案不做）**：KRKR 内核钩子开发（`krkr_bridge.cpp` 上游已含同款实现）；iOS/macOS 适配。

## 2. 架构

```
游戏宿主 Activity（ONScripter / TyranoActivity / RpgMakerActivity / Artemis / KR2 / Framebuffer）
        │  事件源（ExtractFacade 实现）+ 面板/按键组安装 + 手柄路由
        ▼
engine com.core.ons（与宿主同进程）
  OnsExtractBridge   事件解析、编码嗅探、对话-语音配对
  OnsExtractPanel    面板 UI（查词/翻译/TTS/历史/听力/制卡）
  OnsDictStore       词典 SQLite（多词典 v2：dicts 表 + current_dict）
  OnsTranslateClient / OnsMlKitTranslator   翻译双轨
  MultiTtsClient     MultiTTS HTTP 合成
  GameScreenshots    截图落盘（screenshots/<游戏名>/）
  OnsSideButtons     右缘按键组（折叠/点击模式/音量/主页确认）
  OnsVirtualMouse    虚拟鼠标光标层
  OnsSaveCloud   云同步配置（WebDAV / GitHub，提取面板设置分区用）
        ▼
app 层
  ui/screenshots/ScreenshotManagerActivity   主页截图管理
  core/playtime/PlayTimeReader + ui/stats/PlayStatsActivity   游玩统计
  core/engine/runtime/GameRuntimeCatalog|GameRuntimeHost|WebRuntimeAssets   运行时可拆卸
  core/rpgmaker/GameLanguageSupport   五语言文件名编码回退（Web 宿主资源 404 自愈）
```

- AnkiDroid API 为 vendored 源码（`engine/src/main/java/com/ichi2/anki/`，Apache-2.0 头保留），不引入 JitPack 依赖。
- ML Kit 翻译为唯一新增依赖（`com.google.mlkit:translate:17.0.2`，engine）。
- ONS 钩子随 `libonsyuri.so` 分发，`nativeplugins/ons/manifest.json` `pluginVersion 3→4` 触发插件自动重装。
- Web 宿主提取脚本 `assets/__tn_extract.js` 由本地 HTTP 服务器 HTML 注入（`</head>` 前），`onPageFinished` 兜底。

## 3. 交互与键位

- 面板收起时：手柄 RB 呼出面板；右缘文本框键开/关面板。
- 面板展开时：手柄全消费（D-pad 滚动、A 播放、X 复制、Y 词卡/句卡、START 历史开关、B/BACK 三步退出）；键盘 Space/C/Esc 同理。
- 右缘按键组：顶部折叠键收起/展开其余按键（状态持久化，折叠键常驻最顶端，与左缘折叠键同一水平面）；音量键弹百分比滑条直调媒体音量；主页键弹确认后回软件主页面；点击模式键在虚拟鼠标/触摸间切换（图标随状态）。
- 左缘虚拟按键列（ESC/SKIP/AUTO/MENU/OK/NEXT）与右缘按键组同尺寸（40dp）、同风格（深色半透明底 + 白色内容）、各自贴缘。

## 4. 兼容性说明

- 本功能线在 VNLingo（上游最新基线，含 PSP/NS 外置跳转、krkrsdl3 等）之上以「只增不删」原则移植：上游全部既有功能保留，未移除任何入口。
- 移植时对比后跳过的三类**删减类**本地改动（VNLingo 中维持原样）：应用图标替换为系统默认图标、设置页「加入群组」入口移除、游戏卡片无封面占位文字简化。
- 评审调整（二次提交）：①移除游戏内存档管理面板（`OnsSavePanel`）与右缘存档键——条目管理页已有存档导入导出，游戏内不再重复；`OnsSaveCloud`（提取面板设置分区的云同步配置）与 facade 存档数据通道保留；②ONS 编码保持原有 `gbk/sjis/utf8` 三选项，不引入 `auto` 探测（`OnsEncodingDetect` 未移植）。
- 宿主接线采用增量 patch 应用（fuzzy），`ONScripter` / `TyranoActivity` / `RpgMakerActivity` / `ArtemisLauncherBaseActivity` / `KirikiroidLauncherBaseActivity` / `FramebufferGameActivity` / `ArtemisActivity` / `KR2Activity` / `NativeBridge` 均为「上游最新版 + 提取接线」。
- **产品调整（2026-10-05 会话二，用户决定）**：引擎支持裁剪为 krkr/ons/rpgmaker 系列/tyrano/renpy/web/artemis，Siglus/RealLive/AVG32/UK2/FVP/YU-RIS/CatSystem2/PC 与 PSP/NS 外置跳转全链路移除（历史库条目启动报错）；词典管理移至底栏词典页，翻译/云同步设置移至应用设置页（游戏内面板设置只留朗读+显示，分区配置经 `OnsExtractSettingsDialogs` 宿主无关弹窗承载，`OnsTranslateClient` prefs 改 `MODE_MULTI_PROCESS` 跨进程生效）。
- **KRKR 提取现状（2026-10-05 会话三）**：随包 Kirikiroid2 内核（libgame.so/134/126）均为原版构建、无提取导出。接收端已补全（KRKR 宿主装面板+按键组；KR2Activity.setExtractListener 武装），并提供 Label::setString 虚表钩子（krkr_extract_hook.cpp，控制台通道）与 TJS 发射器 v8（kr_extract_tjs 设置，默认关——KAG3.32 引导期段错误复现）。层文本渲染实证不可运行时拦截（内部 FreeType 管线），**对白提取需 krkr2-main 源码带钩内核**，替换内核后 Java 侧零改动生效。krkrsdl3 同理。
- **Artemis 提取（2026-10-05 会话二）**：随包内核（含 clean 内核 .so）均无 extract_bridge 发射器（外部内核源码仓带桥构建未随仓分发），提取数据源由 `artemis_extract_hook.cpp` 运行时补齐——shadowhook（jniLibs 真库 1.1.1，C API 经 dlsym 使用）对 clean 内核 `artc::Compositor::SetMessageLayered`（文本）与 `artc::AudioChannels::Play`（语音名）inline hook，经 `onArtemisExtract` 上行。已知限制：packed 游戏语音字节不可播（内核语音副本落盘机制缺失，facade 退游戏目录语音探测）；官方 revision 内核符号布局不同，不挂钩、无提取。面板触摸放行改为开合显式同步（`setPanelVisibilityHook`）——VISIBLE→GONE 不触发布局回调，仅靠布局监听会让覆盖窗吃掉全部输入（「关闭面板后触摸失灵」根因）。
