# 1. 脚本与工具链

## 1.1 APK 安装脚本（自动检测设备）

- 状态：✅ 已完成
- 脚本示例：`scripts/install-debug-apk.sh`
- 规则要点：
  - 自动检测第一台 `state=device` 的设备；`SERIAL=` 环境变量可覆盖
  - 安装必须显式 `--abi arm64-v8a`（x86_64 模拟器经 ARM 转译，缺省会选错 ABI）
  - `BUILD=1` 先构建再安装；`LAUNCH=1` 安装后拉起主界面
  - 构建 JDK 17；脚本含中文按 §2.1 编码规则保存

## 1.2 ADB 一键授权脚本

- 状态：✅ 已完成
- 脚本示例：`scripts/grant-permissions.sh`
- 规则要点：
  - 授权范围以项目 AndroidManifest 声明为准，随项目增删
  - 运行时权限用 `pm grant`；特殊权限用 `cmd appops set`
  - 逐项尽力而为：OS 级别低于权限引入版本时跳过（如 POST_NOTIFICATIONS 需 API 33+），不中断
  - 授权前提：应用已安装（先跑 §1.1 再跑本脚本）

# 2. 工程与构建

## 2.1 文件编码与 BOM

- 状态：✅ 已完成（规则落地：`.gitattributes` 已入仓）
- 规则要点：
  - 含非 ASCII 的 `.ps1` 必须 UTF-8 **带 BOM**（PowerShell 5.1 无 BOM 按 ANSI 解析）
  - `.sh` **禁止 BOM**（破坏 shebang），UTF-8 无 BOM
  - `.bat` 含中文：首行 `@chcp 65001 >nul`，UTF-8 无 BOM
  - 仓库根 `.gitattributes` 固化：`*.sh eol=lf`、`*.ps1/*.bat eol=crlf`、二进制 `-text`
  - 保存后核验：`file <脚本>`（看 BOM）或读前 3 字节

## 2.2 构建规范

- 状态：✅ 已完成
- 规则要点：
  - JDK 17（`JAVA_HOME` 固定路径）；构建命令 `./gradlew :app:assembleDebug`
  - 磁盘剩余 < 2GB 时禁止构建（Gradle/模拟器都会写满盘）

## 2.3 提交与文档纪律

- 状态：✅ 已完成
- 规则要点：
  - 提交信息 `类型(范围): 摘要`（feat/fix/chore/refactor/docs）
  - 里程碑打注释 tag；不主动 push
  - 会话结束更新进度/记忆/待办三件套
