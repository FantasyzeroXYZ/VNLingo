# 三、材料准备流程（给用户的操作指引）

1. 按上表 📥 项准备游戏压缩包/目录，放入
   `D:\Desktop\模拟器测试材料\<Engine>\`；
2. 在 VNLingo 首页扫描（或手动添加目录）入库；
3. 首次入库的引擎线：回填本清单勾选框 + PROGRESS 记录；
4. 🧪 生成类材料的生成脚本沉淀进 `scripts/`（长期复用）。
