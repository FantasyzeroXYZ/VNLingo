# 1. Agent 测试规范（控制模拟器或手机）

- 状态：已完成（本会话实践沉淀）
- 两条控制路径：
  - **MCP**：android-emulator 插件工具（启动模拟器 / 截图 / UI 树 / 点击）；
    启动模拟器超时概率较高，失败后可回落 ADB 命令行直启
    （`emulator -avd <名> -no-snapshot-save` 后台运行）。
  - **ADB 命令**（主力，零依赖）：
    - 设备检测：`adb devices`（取 `state=device` 行；空则等待或启动模拟器）
    - UI 状态：`uiautomator dump /sdcard/ud.xml` + `cat`（坐标以 dump 为准，
      禁止凭截图记忆硬编码——截图显示尺寸与真实分辨率有缩放差）
    - 操作：`input tap/swipe/text`、`keyevent`；引擎键注入走左右缘按键（模拟点击按键组）
    - 证据：`exec-out screencap -p > xx.png` + `logcat -d | grep <TAG>` 双证据
    - 引擎子进程文件：`run-as com.tyranor.next <cmd>`（读应用私有目录）
- 纪律（踩坑沉淀）：
  - 每次界面变化后**先截图确认再盲点**；点击坐标失效是头号时间杀手
  - uiautomator dump 可能返回陈旧缓存：删文件重 dump，或换文件名
  - 跨进程路径（/sdcard、/data）注意 Git Bash 路径改写：`MSYS_NO_PATHCONV=1`
  - 引擎控制台/警告页会吃按键：盲点前先截图确认当前界面
  - 模拟器启动失败先查目标盘剩余空间（AVD home 所在盘需 2GB+）
- **权限授予纪律**：确定应用所需权限后，**预先写好 adb 一键授权脚本**
  （`pm grant` 运行时权限 + `cmd appops set` 特殊权限，逐项尽力而为不中断），
  测试时脚本一键执行；**禁止每次用 MCP 视觉操作进系统设置页手动点权限**
  ——慢、坐标易漂移、不可复用。VNLingo 参考实现：`scripts/grant-permissions.sh`

# 2. 测试框架选择

- 状态：已完成（选型：Git Bash + ADB + uiautomator 轻量管线）
- 选型结论：
  - **主力**：shell 脚本（Git Bash）+ adb 命令 + uiautomator dump 断言——
    零额外依赖、直接可脚本化长期复用，覆盖安装/授权/启动/提取 smoke/面板断言
  - **不引入**：Appium/UIAutomator2 服务端（部署重、维护成本高）；
    Espresso/instrumented 测试仅在需要应用内 UI 单测时按需补充
- 复用原则：同一测试流程被手动执行 **3 次以上**，即固化为 `scripts/` 脚本
  （参考 §4 脚本清单）；一次性验证交互完成后记录 PROGRESS 即可

# 3. 测试执行流程（标准顺序）

- 状态：已完成
- 流程：
  1. `scripts/install-debug-apk.sh`（`BUILD=1` 可选；自动检测设备）
  2. `scripts/grant-permissions.sh`（权限授权）
  3. 启动游戏（主页卡片坐标现取现点）→ 推进至目标场景
  4. 按测试项逐项验证（见测试材料与测试事项清单文档 §二）
  5. `logcat -d | grep <TAG>` 收集证据 + 关键节点截图
- 证据归档：截图/日志属临时产物，验证完即删（见 §4 清理）

# 4. 测试缓存与垃圾清理

- 状态：已完成（`scripts/check-garbage.sh` 只读报告 + `scripts/cleanup.sh` 选择性清理）
- 垃圾堆积点（实测体积）：
  - `app/build` + `engine/build` + `.gradle`：单次全量构建后约 1.6GB
  - AVD `snapshots/default_boot` + `cache.img.qcow2`：约 2.5GB
    （`-no-snapshot-save` 流程下快照无用，可删）
  - 未使用的其他 AVD：每个 4GB+（删除需确认，可经 AVD Manager 重建）
  - 仓库临时目录（`.tmp-test` 等）与 `D:\dev-cache\tmp`
- 原则：
  - 清理脚本必须**选择性**（分项开关），禁止一把梭全删
  - 用户数据（AVD userdata 内已装游戏/存档）永不触碰
  - 检查脚本只读；清理脚本带分项回显
